## 📄 营业执照准备

### 准备要求

**格式要求：**

```
□ 彩色扫描件或高清拍照
□ 加盖企业公章（红色公章清晰可见）
□ 文字信息清晰可读
□ 营业执照在有效期内
□ 营业执照边框完整
```

**文件格式：**

```
□ PDF 格式（推荐）
□ JPG/JPEG 格式（备选）
□ PNG 格式（备选）
□ 文件大小：建议 2-5MB
□ 分辨率：≥300dpi
```

### 准备步骤

**Step 1: 获取营业执照原件**

```
□ 向公司行政部门申请
□ 确认营业执照在有效期内
□ 检查营业执照信息是否最新
```

**Step 2: 扫描或拍照**

```
推荐方式：使用扫描仪
□ 分辨率设置：300dpi 或更高
□ 颜色模式：彩色
□ 文件格式：PDF

备选方式：手机拍照
□ 使用扫描类APP（如扫描全能王、Microsoft Lens）
□ 光线充足，避免反光
□ 保持营业执照平整
□ 边框完整，四角入镜
```

**Step 3: 加盖公章**

```
方式一：实体公章
□ 在营业执照复印件上加盖公章
□ 公章完整、清晰
□ 公章位置：一般在右下角或中间位置
□ 然后扫描或拍照

方式二：电子公章（部分平台接受）
□ 使用公司电子公章系统
□ 在扫描件上加盖电子公章
□ 确保电子公章合法有效
```

**Step 4: 检查质量**

```
□ 公司名称清晰可读
□ 统一社会信用代码清晰可读
□ 注册地址清晰可读
□ 法定代表人清晰可读
□ 公章清晰可见
□ 有效期清晰可读
□ 发证机关清晰可读
□ 无折痕、污渍、遮挡
```

**Step 5: 准备多份备用**

```
建议准备文件：
□ 营业执照扫描件（PDF）
□ 营业执照扫描件（JPG）
□ 营业执照副本复印件（加盖公章，PDF）
□ 营业执照副本复印件（加盖公章，JPG）

存储位置：
□ 本地电脑
□ 云盘备份
□ 企业文档管理系统
```

## 📜 软件著作权申请

### 为什么需要软著？

**必须提供的平台：**

- ✅ 华为应用市场 - 强制要求
- ⚠️ 小米应用商店 - 强烈建议（提高通过率）
- ⚠️ OPPO软件商店 - 建议提供
- ⚠️ vivo应用商店 - 建议提供

**软著的好处：**

```
1. 提高审核通过率（约提升 30-40%）
2. 保护知识产权
3. 企业正规化标志
4. 后续版权纠纷的法律依据
5. 部分地区有政府补贴（通常 100-500元/件）
```

### 申请方式对比

| 对比项 | 自己申请（普通） | 自己申请（加急） | 代理申请 |
|--------|----------------|----------------|----------|
| **费用** | 300元 | 1000-3000元 | 800-2000元 |
| **周期** | 2-3个月 | 3-7天 | 根据加急程度 |
| **难度** | 中等 | 中等 | 简单 |
| **推荐度** | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

**建议：选择自己申请（加急）**

- 费用适中（约1500-2000元）
- 周期可控（3-7天）
- 不影响上架进度

### 申请流程

**Step 1: 注册账号**

访问：中国版权保护中心

- 官网：<https://www.ccopyright.com.cn/>
- 注册企业账号
- 完成实名认证

**Step 2: 准备申请材料**

```
必需材料：
□ 软件著作权登记申请表
  - 在线填写后系统生成
  - 需加盖公章

□ 软件源代码
  - 前后各连续 30页
  - 共 60页（约 3000行代码）
  - 每页不少于 50行
  - 需要有页眉（软件名称和版本号）

□ 软件说明书或设计文档
  - 至少 10页
  - 内容包括：软件功能、使用说明、技术特点等

□ 企业营业执照副本复印件
  - 加盖公章

□ 法定代表人身份证复印件
  - 正反面
  - 加盖公章
```

**源代码准备示例：**

```dart
// 页眉格式（每页顶部）：
// 您的应用 V1.0.0

// 选择代码文件（从 lib/ 目录）：
1. lib/main.dart（前30行）
2. lib/core/di/service_locator.dart
3. lib/features/auth/application/auth_provider.dart
4. lib/features/service_order/presentation/workbench_page/workbench_page.dart
... 等等

// 生成PDF：
□ 设置页眉：软件名称和版本号
□ 设置行号（可选）
□ 字体：宋体或等宽字体
□ 字号：小四或五号
□ 边距：2.5cm
□ 每页 50-60行代码
```

**说明书内容大纲：**

```markdown
1. 软件概述
   - 软件名称：您的应用
   - 版本号：V1.0.0
   - 开发平台：Flutter
   - 适用平台：Android、iOS

2. 软件功能介绍
   - 用户登录认证
   - 订单管理
   - 工作台统计
   - 消息中心
   - 个人中心设置

3. 运行环境
   - Android 5.0 及以上
   - iOS 11.0 及以上

4. 使用说明
   - 安装方法
   - 主要功能操作流程
   - 截图说明

5. 技术特点
   - 采用 Flutter 跨平台框架
   - DDD 架构设计
   - 状态管理：Riverpod
   - 网络请求：Dio
   ...（参考项目 README.md）
```

**Step 3: 在线提交申请**

```
□ 登录中国版权保护中心网站
□ 进入"计算机软件著作权登记"
□ 填写申请表

□ 选择办理方式

  - 加急办理：3、6、11、16、21、26、31 工作日（费用递增）
  - 特急办理：1-2 工作日（费用最高，约3000元）
□ 支付费用
□ 等待审核
```

**Step 4: 材料邮寄（如需要）**

**Step 5: 跟踪进度**

### 软著申请注意事项

**软件名称规范：**

```
✅ 正确示例：
- 您的应用软件 V1.0
- 您的应用服务人员管理系统 V1.0
- 您的应用护理服务平台 V1.0

❌ 避免：
- 名称过长（超过40个字符）
- 包含特殊符号

```

**版本号说明：**

```
□ 使用当前应用版本号：V1.0.0 或 V1.0
□ 保持与应用版本一致
□ 每次大版本更新建议重新申请软著
```

**代理申请建议：**

```
如果时间紧急或不熟悉流程，可以考虑代理申请：

优点：
□ 专业指导，材料准备规范
□ 通过率高
□ 省时省力

缺点：
□ 费用较高（代理费 + 官费）
□ 需要提供材料给代理公司

如何选择代理：
□ 选择正规代理机构（有中国版权保护中心授权）
□ 比较价格和服务
□ 查看成功案例
□ 签订正式合同
```

## 📋 其他资质说明

### ICP 备案

**什么是ICP备案？**

ICP备案是指互联网信息服务备案，主要针对提供信息发布服务的网站和应用。

**您的应用是否需要？**

根据您的应用特点评估：

```
可能需要 ICP 备案的情况：
□ 应用内有系统公告、新闻发布功能 ✅（您的应用有）
□ 应用内有用户评论、社区功能
□ 应用内有UGC内容（用户生成内容）
□ 应用有独立的官方网站

可能不需要的情况：
□ 纯工具类应用，无信息发布
□ 仅展示订单信息，无公开发布功能
```

**建议：**

- 咨询当地通信管理局确认是否需要
- 如果应用仅对内部服务人员使用，可能不需要
- 如果应用有公开下载和使用，建议申请备案

**如何申请ICP备案？**

```
1. 准备材料：
   □ 营业执照
   □ 法人身份证
   □ 域名证书（如有官网）
   □ 服务器接入商信息

2. 申请流程：
   □ 在服务器提供商处提交备案申请（如阿里云、腾讯云）
   □ 填写备案信息
   □ 提交审核
   □ 管局审核（7-20个工作日）
   □ 获得备案号

3. 备案号格式：
   例如：闽ICP备12345678号
```

### 增值电信业务经营许可证

**什么是增值电信业务经营许可证？**

通常所说的"ICP许可证"或"ICP经营许可证"，针对经营性互联网信息服务。

**您的应用是否需要？**

```
需要的情况：
□ 应用内有在线支付功能
□ 应用内有电商交易功能
□ 应用收取服务费用
□ 应用销售虚拟商品

您的应用：
□ 仅展示订单信息 ✅
□ 不涉及线上支付
□ 不涉及交易撮合
□ 暂时不需要 ✅
```

**如果以后需要：**

- 申请周期：1-3个月
- 申请费用：约 3000-8000元（含代理）
- 需要先完成 ICP 备案
- 建议找专业代理机构协助

## 💡 常见问题

**Q: 软著申请一定要加急吗？**

A: 强烈建议加急。普通申请需要2-3个月，会严重拖延上架进度。加急3-7天费用约1500-2000元，性价比高。

**Q: 营业执照扫描件必须加盖公章吗？**

A: 是的，所有应用市场都要求加盖公章。建议在复印件上加盖后再扫描。

**Q: 软著证书上的软件名称必须与应用名称一致吗？**

A: 不一定完全一致，但建议尽量接近。例如：

- 应用名：您的应用
- 软著名：您的应用软件 V1.0

**Q: 没有软著能上架吗？**

A:

- 华为应用市场：必须有软著
- 其他Android市场：大部分可以，但建议提供
- Apple App Store：不需要软著

**Q: 个人开发者需要营业执照吗？**

A: 您的应用是企业应用，必须使用企业账号，需要营业执照。个人开发者不需要营业执照，但功能和权限受限。
