## 🏢 华为应用市场

### 平台信息

**官网：** <https://developer.huawei.com/consumer/cn/>  
**开发者中心：** <https://developer.huawei.com/consumer/cn/service/josp/agc/index.html>  
**审核周期：** 1-3个工作日  
**审核难度：** 较严格  
**特点：** 中国最大的Android应用市场之一，华为设备预装，用户量大

### 注册开发者账号

**Step 1: 访问开发者中心**

```
1. 打开：https://developer.huawei.com/consumer/cn/
2. 点击右上角"登录/注册"
3. 使用华为账号登录（如没有，先注册华为账号）
```

**Step 2: 完善账号信息**

```
1. 登录后进入"管理中心"
2. 选择"实名认证" → "企业实名认证"
3. 填写企业信息：
   - 企业全称（与营业执照一致）
   - 统一社会信用代码
   - 法人姓名
   - 法人身份证号
4. 上传资料：
   - 营业执照扫描件（加盖公章）
   - 法人身份证正反面
   - 申请人身份证正反面（如非法人）
   - 授权书（如非法人申请）
5. 提交审核
6. 等待审核结果（1-3个工作日）
```

**Step 3: 签署协议**

```
认证通过后：
1. 签署《华为开发者服务协议》
2. 完成安全培训
3. 账号激活
```

### 创建应用

**Step 1: 进入应用管理**

```
1. 登录 AppGallery Connect
   https://developer.huawei.com/consumer/cn/service/josp/agc/index.html
2. 点击"我的应用" → "创建应用"
3. 选择"Android应用"
```

**Step 2: 填写基本信息**

```
应用名称：好适到家
或：好适到家-服务人员端

应用包名：harborapp.zhiyouxia.net.skyHarborServiceApp
（必须与APK中的包名一致）

应用分类：
- 主分类：生活服务 或 商务办公
- 次分类：根据选项选择最合适的

应用类型：应用

目标用户年龄段：18+
```

**Step 3: 填写详细信息**

```
应用简介（一句话）：
专业家政服务人员工作管理平台，高效接单、智能排班、轻松服务

应用介绍（详细）：
（粘贴您准备好的详细描述，500-1000字）

应用图标：
- 上传 512x512 PNG
- 确保清晰，无白边

应用截图：
- 至少3张，最多5张
- 尺寸：1080x1920 或 1080x2340
- 格式：PNG或JPG
- 按顺序上传

宣传视频（可选）：
- 格式：MP4
- 大小：≤30MB
- 时长：15-30秒
```

**Step 4: 上传APK**

```
1. 点击"版本信息" → "新增版本"
2. 上传APK文件：
   - 选择 app-arm64-v8a-release.apk
   - 或者已加固的APK
3. 系统自动解析：
   - 版本号：1.1.0
   - 版本代码：1
   - 包名：自动识别
   - 权限列表：自动识别
4. 填写版本更新说明：
   - 首次发布说明
5. 确认

重要：
□ APK必须已签名
□ 版本代码必须大于已上架版本（如是更新）
□ 包名必须与应用信息一致
```

**Step 5: 填写资质信息**

```
软件著作权：
- 上传软著证书扫描件（必需）
- 证书编号：软著登字第XXXXXXXX号
- 软件全称：好适到家服务人员端软件 V1.1

隐私政策：
- 填写隐私政策URL
- https://yourdomain.com/privacy-policy
- 确保链接可访问

用户协议：
- 填写用户服务协议URL
- https://yourdomain.com/user-agreement
- 确保链接可访问

应用权限说明：
根据APK中的权限，逐一说明用途：
- 网络权限：获取订单数据、上传服务记录
- 相机权限：拍摄服务照片、记录服务过程
- 相册权限：选择照片上传
- 电话权限：一键拨打客户电话
```

**Step 6: 内容分级**

```
根据应用内容选择：
□ 无不适宜内容
□ 年龄分级：18+
□ 内容标签：根据实际选择
```

**Step 7: 联系信息**

```
客服电话：__________
客服邮箱：__________
官方网站：__________（如有）
```

**Step 8: 提交审核**

```
1. 预览应用信息
2. 确认所有信息准确无误
3. 勾选"我已阅读并同意相关协议"
4. 点击"提交审核"
5. 记录提交时间
```

### 审核跟踪

```
查看审核状态：
1. 登录 AppGallery Connect
2. 我的应用 → 选择应用 → 版本信息
3. 查看审核状态：
   - 审核中
   - 审核通过
   - 审核驳回

审核通知方式：
□ 站内信
□ 邮件通知
□ 短信通知（如已设置）

审核周期：
- 通常1-3个工作日
- 节假日会延长
```

### 华为特殊要求

**必需资质：**

- ✅ 软件著作权证书（强制）
- ✅ 隐私政策网页
- ✅ 企业营业执照

**审核要点：**

- 应用稳定性（无闪退）
- 权限使用合理
- 隐私政策完整
- 软著信息准确
- 内容合法合规

**常见拒审原因：**

1. 缺少软著证书
2. 软著证书与应用名称不符
3. 隐私政策不完整
4. 权限使用无说明
5. 应用闪退或功能异常

4. 通知团队
5. 开始推广
```

4. 重新提交
5. 跟踪审核状态
```
