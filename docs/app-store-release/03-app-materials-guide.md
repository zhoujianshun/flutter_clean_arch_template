## 🎨 应用图标制作

### 图标规范要求

**Android 应用市场：**

```
尺寸：512x512 像素
格式：PNG（推荐）或 JPG
大小：≤1MB
要求：
□ 正方形
□ 可以有透明背景（但不推荐）
□ 边缘清晰
□ 无白边
```

**iOS App Store：**

```
尺寸：1024x1024 像素
格式：PNG
大小：≤1MB
要求：
□ 正方形
□ 不能有透明通道（Alpha通道）
□ 不能有圆角（系统会自动添加）
□ 不能有图层效果
□ 颜色空间：RGB
```

### 当前图标状态

根据您的项目配置：

```yaml
# flutter_launcher_icons.yaml 已配置
✅ 应用已有 launcher_icon
✅ 图标文件位置：assets/app/1024.png

需要额外导出：
□ 512x512 PNG（Android 应用市场）
□ 1024x1024 PNG（iOS App Store，确保无透明通道）
```

### 图标导出步骤

**从现有图标导出：**

```bash
# 如果您有原始设计文件（AI、Sketch、Figma等）

# 1. 导出 Android 版本（512x512）
- 尺寸：512x512 px
- 格式：PNG
- 命名：app_icon_512.png

# 2. 导出 iOS 版本（1024x1024）
- 尺寸：1024x1024 px
- 格式：PNG（去除透明通道）
- 命名：app_icon_1024.png

# 3. 如果只有 1024.png，可以用工具调整
# 使用 ImageMagick（命令行工具）
brew install imagemagick

# 生成 512x512
convert assets/app/1024.png -resize 512x512 app_icon_512.png

# 去除透明通道（iOS要求）
convert assets/app/1024.png -background white -alpha remove -alpha off app_icon_1024_no_alpha.png
```

**使用在线工具：**

- <https://www.canva.com/> - 在线设计
- <https://www.remove.bg/> - 去除背景
- <https://tinypng.com/> - 压缩图片

### 图标设计建议

**设计原则：**

```
✅ 简洁明了 - 一眼能认出是什么
✅ 高辨识度 - 在小尺寸下依然清晰
✅ 符合品牌 - 与应用主题一致
✅ 颜色鲜明 - 在各种背景下都醒目
✅ 避免文字 - 除非是品牌LOGO的一部分
✅ 居中对称 - 视觉平衡
```

**检查清单：**

```
□ 图标在 512x512 下清晰可见
□ 图标在 64x64 下依然可识别（桌面显示尺寸）
□ 图标在浅色背景下清晰
□ 图标在深色背景下清晰
□ 图标无锯齿、无模糊
□ 图标无白边或黑边
□ iOS版本无透明通道
```

## 📸 应用截图制作

### 截图规范要求

**Android 应用市场：**

| 应用市场 | 尺寸要求 | 数量要求 | 格式 | 大小 |
|---------|---------|---------|------|------|
| **华为** | 1080x1920 或 1080x2340 | 至少3张，最多5张 | PNG/JPG | 每张≤8MB |
| **小米** | 1080x1920 或 1080x2340 | 至少3张，最多5张 | PNG/JPG | 每张≤5MB |
| **OPPO** | 1080x1920 | 至少3张，最多5张 | PNG/JPG | 每张≤5MB |
| **vivo** | 1080x1920 | 至少3张，最多5张 | PNG/JPG | 每张≤5MB |
| **应用宝** | 1080x1920 | 至少3张，最多5张 | PNG/JPG | 每张≤5MB |

**推荐尺寸：1080x2340**（19.5:9 全面屏比例）

**iOS App Store：**

| 设备类型 | 尺寸 | 是否必需 |
|---------|------|----------|
| iPhone 6.7" | 1290x2796 或 1284x2778 | ✅ 必需 |
| iPhone 6.5" | 1242x2688 | 推荐 |
| iPhone 6.1" | 1179x2556 | 可选 |
| iPhone 5.5" | 1242x2208 | 可选 |

每个尺寸：至少3张，最多10张

### 截图内容规划

根据您的应用功能，建议截取以下页面（按优先级排序）：

**必需截图（前5张）：**

1. **登录/欢迎页**
   - 展示应用品牌和名称

2. **工作台首页**

3. **订单列表页**
   - 展示订单管理功能
   - 展示列表样式
   - 展示筛选功能

4. **订单详情页**
   - 展示详细信息
   - 展示操作按钮
   - 展示服务记录
   - 文件路径：`lib/features/service_order/presentation/service_order_detail_page/`

5. **个人中心页**
   - 展示个人信息
   - 展示设置选项
   - 展示其他功能入口

**可选截图（第6-10张）：**

6. **消息中心页**
   - 展示消息列表
   - 展示未读消息提示

7. **系统公告详情**
   - 展示公告内容
   - 展示富文本显示

8. **设置页面**
   - 展示主题切换
   - 展示语言切换
   - 展示其他设置项

9. **应用特色功能页**

### 截图常见错误

**❌ 避免以下情况：**

```
□ 截图模糊、有锯齿
□ 包含真实用户个人信息
□ 包含测试数据（如"张三"、"测试订单"）
□ 包含错误提示或异常状态
□ 截图不完整（顶部或底部被截断）
□ 截图有水印或其他应用的UI元素
□ 文字太小看不清
□ 颜色太暗或太亮
□ 背景杂乱
□ 功能说明文字过多（遮挡截图）
```

## 🎬 应用宣传视频制作

### 视频规范要求

**Android 应用市场：**

```
时长：15-30秒（推荐20-25秒）
格式：MP4
大小：≤30MB
分辨率：1080x1920（竖屏）
帧率：24fps 或 30fps
编码：H.264
```

**iOS App Store：**

```
时长：15-30秒
格式：MOV 或 MP4
大小：≤500MB
分辨率：与截图尺寸一致（1290x2796、1242x2688等）
帧率：25-30fps
编码：H.264 或 HEVC
```

### 视频内容规划

**15-30秒视频结构：**

```
0-3秒：开场
□ 显示应用图标和名称
□ 显示应用口号
□ 吸引注意力

3-10秒：核心功能展示（第1组）
□ 工作台功能
□ 订单管理功能
□ 配合简短文字说明

10-20秒：核心功能展示（第2组）
□ 订单详情查看
□ 服务记录上传
□ 消息通知功能

20-25秒：总结和引导
□ 突出核心优势
□ 显示应用名称
□ 引导下载

25-30秒：结束画面
□ 显示应用图标
□ 显示下载提示（如适用）
```

### 视频制作方法

**方式1：录屏 + 剪辑（推荐新手）**

```
工具：
- Android 录屏：系统自带或 AZ Screen Recorder
- iOS 录屏：系统自带（控制中心 → 屏幕录制）
- 剪辑：剪映（免费，简单易用）

步骤：
1. 准备脚本
   - 列出要展示的功能
   - 规划操作顺序
   - 预计时长

2. 录制屏幕
   - 开启屏幕录制
   - 按照脚本操作应用
   - 动作流畅、不卡顿
   - 录制多次，选最好的

3. 剪辑视频
   - 导入剪映
   - 裁剪多余部分
   - 调整播放速度（可加速1.2-1.5倍）
   - 添加转场效果
   - 添加背景音乐（轻快、不喧宾夺主）
   - 添加文字说明

4. 导出视频
   - 分辨率：1080x1920
   - 帧率：30fps
   - 格式：MP4
   - 质量：高
```

**方式2：专业制作（推荐有预算）**

```
工具：
- Adobe Premiere Pro
- Final Cut Pro（Mac）
- After Effects（加动画效果）

优势：
□ 更专业的效果
□ 更丰富的动画
□ 更精细的调色
□ 更好的音效

步骤：
1. 制作脚本和分镜
2. 录制高质量素材
3. 专业剪辑和调色
4. 添加动画和特效
5. 音效和配乐
6. 导出适配各平台
```

**方式3：请专业团队（预算充足）**

```
费用：3000-10000元
周期：3-7天

优势：
□ 高质量视频
□ 专业脚本策划
□ 专业配音（可选）
□ 多版本适配

注意：
□ 提供应用APK/IPA
□ 说明核心功能
□ 提供品牌VI（颜色、字体等）
□ 确认交付格式和尺寸
```

### 视频制作技巧

**录屏技巧：**

```
✅ 关闭通知提示
✅ 使用飞行模式（避免来电）
✅ 充满电（避免低电量提示）
✅ 清空状态栏不必要的图标
✅ 设置统一时间（如10:00）
✅ 保持手势流畅
✅ 避免快速滑动（容易模糊）
```

**剪辑技巧：**

```
✅ 节奏紧凑，不拖沓
✅ 突出核心功能
✅ 添加适当转场（不要过度）
✅ 文字简洁明了
✅ 配乐不要太响（音量约30-40%）
✅ 保持统一风格
```

**文字说明建议：**

```
0-3秒："您的应用"
       "高效管理，轻松服务"

3-10秒："订单管理 一目了然"
        "实时同步 快速响应"

10-20秒："服务记录 便捷上传"
         "客户评价 随时查看"

20-25秒："提升效率 优质服务"
         "您的应用 服务人员首选"
```

### 视频可选或不需要

```
✅ 可选准备：
- 如果时间充足，强烈建议制作
- 能显著提升下载转化率（约15-25%）
- 展示应用动态效果更直观

❌ 可以跳过：
- 时间紧迫
- 预算不足
- 应用功能相对简单（静态截图已足够展示）

建议：
- 首次上架可以不提供视频
- 后续优化时再补充视频
```

│   │   │   └── 05_profile.png
│   │   │
│   │   └── 6.5inch/               # iPhone 11 Pro Max
│   │       └── ...
│   │
│   └── raw/                       # 原始截图（未美化）
│       ├── android_raw/
│       └── ios_raw/

│   ├── promo_video_android.mp4    # Android 宣传视频
│   ├── promo_video_ios.mov        # iOS 宣传视频

    ├── icon_design.ai             # 图标设计文件
    ├── screenshot_template.fig    # Figma 截图模板

### 文件命名规范

```
图标：
app_icon_{size}.png
例如：app_icon_512.png, app_icon_1024.png

截图：
{platform}_{order}_{page_name}.png
例如：android_01_login.png, ios_02_workbench.png

视频：
promo_video_{platform}_{version}.mp4
例如：promo_video_android_v1.mp4
```
