## 🎯 准备工作

### 前置要求检查

在开始之前，确认以下内容已准备就绪：

**账号准备：**
- [ ] Apple Developer 账号已激活
- [ ] 支付方式已配置（$99/年 或 $299/年）
- [ ] 开发者协议已同意

**技术准备：**
- [ ] IPA 文件已构建
- [ ] 已上传到 App Store Connect
- [ ] Build 在 App Store Connect 中可见
- [ ] 所有功能测试通过

**素材准备：**
- [ ] 应用图标（1024x1024 PNG，无透明通道）
- [ ] 截图（至少3张，1290x2796 或 1242x2688）
- [ ] 应用预览视频（可选）

**文案准备：**
- [ ] 应用名称和副标题
- [ ] 应用描述和推广文本
- [ ] 关键词（100字符）
- [ ] 隐私政策URL
- [ ] 支持URL
- [ ] 版本更新说明

**审核准备：**
- [ ] 测试账号信息
- [ ] 审核说明（Review Notes）
- [ ] 联系方式（24/7可用）

## 👨‍💻 Apple Developer账号

### 账号类型选择

**个人账号（Apple Developer Program）**

```
费用：$99/年
适用场景：个人开发者
应用发布：App Store公开下载
优点：费用低，申请简单
缺点：功能有限，无法企业内部分发
```

**企业账号（Apple Developer Enterprise Program）**

```
费用：$299/年
适用场景：企业应用，内部分发
应用发布：企业内部分发，不能上架App Store
优点：可以内部分发，不需要审核
缺点：费用高，申请严格，不能公开发布
```

**推荐：个人账号（用于App Store发布）**

### 注册流程

**Step 1: 准备Apple ID**

```
1. 访问：https://appleid.apple.com/
2. 创建或使用已有Apple ID
3. 建议使用企业邮箱（更专业）
4. 完成双重认证设置
```

**Step 2: 加入Apple Developer Program**

```
1. 访问：https://developer.apple.com/programs/enroll/
2. 点击"Start Your Enrollment"
3. 使用Apple ID登录
4. 选择账号类型：
   - Individual（个人）或
   - Organization（企业）

如选择Organization（企业）：
□ 需要邓白氏编码（D-U-N-S Number）
□ 如没有，Apple会协助申请（免费，约2周）
□ 需要营业执照
□ 需要法人授权
```

**Step 3: 填写信息**

```
企业信息（如选择Organization）：
- 公司全称（中英文）
- 公司注册地址
- 联系人信息
- 邓白氏编码
- 法人信息

个人信息（如选择Individual）：
- 姓名
- 地址
- 联系方式
```

**Step 4: 支付费用**

```
1. 选择支付方式：
   - 信用卡（推荐）
   - 借记卡
   - 支付宝（部分地区）
2. 支付 $99（个人）或 $299（企业）
3. 保存收据
```

**Step 5: 等待审核**

```
审核周期：
- 个人账号：1-2个工作日
- 企业账号：5-10个工作日（需要验证邓白氏编码）

审核通过后：
- 收到激活邮件
- 可以登录开发者中心
- 可以访问App Store Connect
```

### 账号激活后

**必做事项：**

```
1. 同意开发者协议
   - 登录 developer.apple.com
   - 点击"Agreements, Tax, and Banking"
   - 阅读并同意协议

2. 配置税务信息（如需要）
   - 填写税务表格
   - 根据地区填写相应信息

3. 配置银行信息（如应用收费）
   - 添加银行账户
   - 用于接收应用收入

4. 创建Team
   - 查看Team ID
   - 添加团队成员（如需要）
```

## 🚀 提交审核

### 最后检查

在点击"提交审核"前，确认：

```
✓ App信息完整
✓ 隐私信息已填写
✓ 截图已上传（至少3张）
✓ 描述和关键词已填写
✓ 构建版本已选择
✓ 测试账号已提供
✓ 审核说明已填写
✓ 联系方式可用
✓ 隐私政策URL可访问
✓ 支持URL可访问
```

### 提交步骤

```
1. 在App Store Connect中
2. 选择您的应用
3. 左侧菜单 → App Store
4. iOS App → 当前版本
5. 滚动到页面底部
6. 点击"提交以供审核"
7. 回答出口合规问题：
   - 您的App是否使用加密？
   - 通常选择"否"（除非特殊情况）
8. 勾选确认：
   ☑ 我已阅读并同意Apple的审核指南
9. 点击"提交"

提交成功！
- 状态变为"正在等待审核"
- 您会收到确认邮件
```

## 📊 审核跟踪

### 审核状态

```
审核状态说明：

1. 准备提交
   - 您正在填写信息
   - 尚未提交

2. 正在等待审核
   - 已提交，排队等待
   - 通常等待1-2天

3. 正在审核
   - 审核人员正在审核
   - 通常1-24小时

4. 待开发人员发布
   - 审核通过！
   - 等待您手动发布

5. 可供销售
   - 已发布
   - 用户可以下载

6. 被拒绝
   - 审核未通过
   - 查看拒审原因
   - 需要修复后重新提交
```

### 查看审核状态

```
方式1: App Store Connect
1. 登录 appstoreconnect.apple.com
2. 我的App → 选择应用
3. App Store → iOS App
4. 查看当前状态

方式2: App Store Connect App
1. 下载"App Store Connect"应用（iOS）
2. 登录
3. 查看应用状态
4. 接收推送通知

方式3: 邮件通知
- 状态变更时会收到邮件
- 建议开启邮件通知
```

### 审核时长

```
典型审核周期：

正常情况：
- 等待审核：0.5-2天
- 正在审核：2-24小时
- 总计：1-3天

特殊情况：
- 节假日：+2-5天
- 复杂应用：+1-2天
- 首次提交：可能略长
```

## ❌ 被拒绝处理

### 查看拒审原因

```
1. 登录App Store Connect
2. 选择应用
3. App Store → iOS App
4. 点击"Resolution Center"（审核处理中心）
5. 查看详细的拒审原因
```

### 常见拒审原因

**1. 应用崩溃（最常见）**

```
原因：审核人员使用时应用崩溃
解决：
- 修复崩溃问题
- 充分测试
- 使用Xcode查看崩溃日志
- 重新提交
```

**2. 测试账号问题**

```
原因：
- 测试账号无法登录
- 验证码无法接收
- 账号功能不完整

解决：
- 提供新的测试账号
- 确保账号可用
- 详细说明登录方式
- 提供24/7联系方式
```

**3. 隐私政策问题**

```
原因：
- 隐私政策链接无法访问
- 隐私政策内容不完整
- 未说明数据收集

解决：
- 确保链接可访问
- 补充隐私政策内容
- 说明所有收集的数据
```

**4. 权限使用说明不足**

```
原因：
- 权限用途说明不清
- 权限申请时机不当

解决：
- 在Info.plist中详细说明
- 在审核说明中补充
- 优化权限申请时机
```

**5. 功能不完整**

```
原因：
- 应用功能不完整
- 与描述不符

解决：
- 完善应用功能
- 或调整应用描述
- 确保功能可用
```

